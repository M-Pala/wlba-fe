# AI Usage Disclosure

This project was built with assistance from AI coding tools, as permitted by the Woliba React Coding Challenge.

## Tools used

- **Cursor IDE** (Agent mode) — implementation, refactoring, and code review
- **Claude** — architecture suggestions, bug identification, and documentation drafts

## How AI was used

| Area              | AI contribution                                                              |
| ----------------- | ---------------------------------------------------------------------------- |
| Project structure | Suggested folder layout aligned with the assignment spec                     |
| API integration   | Helped wire Axios clients, Vite proxy, and error-message helpers             |
| UI components     | Assisted with reusable `TextField`, `OtpInput`, `BackButton`, and step forms |
| Documentation     | Drafted `README.md` structure and setup instructions                         |

## Human oversight

All API calls, validation rules, Redux state shape, and final UI behavior were reviewed and tested manually. Sample credentials and live API responses were verified against the official API documentation.
